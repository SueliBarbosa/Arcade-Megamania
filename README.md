# Arcade Megamania

Recriação do clássico jogo de tiro espacial (shmup) de tela fixa **Megamania** do Atari 2600 em um único arquivo HTML5 (Canvas + JavaScript puro).

## Características

- Resolução interna clássica 320x240 com escala inteira proporcional.
- Sprites em pixel art 8-bit desenhados diretamente em código.
- Inimigos clássicos em ciclos de fases:
  1. Hambúrgueres voadores
  2. Bolachas / biscoitos
  3. Ferros de passar roupa
  4. Gravatas-borboleta
  5. Diamantes
- Efeitos sonoros sintetizados via Web Audio API.
- Barra de energia com consumo contínuo e bônus de fase.
- Controles por teclado e suporte a toque para dispositivos móveis.

## Como Jogar

Abra o arquivo `index.html` diretamente no seu navegador.

### Controles
- **Setas Esquerda/Direita** ou **A / D**: Mover a nave
- **Espaço**: Atirar / Iniciar jogo
- **Enter**: Reiniciar
- **Dispositivos Móveis**: Botões direcionais e de tiro na tela, ou toque/arraste no canvas
